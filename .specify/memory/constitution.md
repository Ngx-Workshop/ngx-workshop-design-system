# Constitution

1. Match the Shell: Angular, Material and CDK 21.1.0; TypeScript 5.9.3.
2. Material and CDK own established control behavior, focus, overlays and keyboard interaction.
3. Public Ngx semantic CSS tokens are the theme contract. Material adapters live in one Sass entry point.
4. Custom components use standalone APIs, signals, OnPush and semantic HTML.
5. Keyboard operation, visible focus, reduced motion and readable contrast are defaults.
6. Specify observable outcomes, then plan, track tasks, implement and record real validation.
7. Keep the package consumable independently of Storybook. No private Material selectors or deployment coupling.
