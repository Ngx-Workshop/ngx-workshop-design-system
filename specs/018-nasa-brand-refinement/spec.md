# NASA brand refinement

Status: Complete
Created: 2026-10-28

Refine the existing NASA pair in response to the supplied NASA brand guidelines.

- FR-001 / AC-001: NASA selection uses Inter headings, Public Sans body/interface text, and DM Mono small labels/numbers, including Material overlays. Fonts are packaged and work offline.
- FR-002 / AC-002: Use official NASA blue #0032a0 and red #e4002b as brand references, with readable semantic shades on light and dark surfaces. All established contrast pairs remain at least 4.5:1.
- FR-003 / AC-003: Grid panels show a visible soft repeating full-color insignia without grid lines. Logos repeat every 144px with alternating rows offset 72px and a 120px row pitch. Light-mode glass must visibly blur contrasting artwork behind a translucent surface. Switching away restores original typography/grid.
- FR-004 / AC-004: Preserve existing uncommitted overlay/surface work. Build library, demo, Storybook and packed consumer; verify fonts, surface variants, switching, contrast and responsive layout.

Source: https://www.nasa.gov/nasa-brand-center/brand-guidelines/ (2026-10-28). Digital typography section and insignia color chart. These supersede feature 015 typography/asset scope. No deployment requested.
