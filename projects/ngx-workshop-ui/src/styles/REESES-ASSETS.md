# Reese’s theme sources

The orange #ff5d00, yellow #ffc000 and chocolate #2f1c0b references were provided by the user (2026-10-29). They are exposed as --ngx-reeses-orange, --ngx-reeses-yellow and --ngx-reeses-chocolate. Dark mode uses the exact orange/yellow as semantic accents and chocolate as its base surface. Light mode darkens orange and uses chocolate for secondary accents to retain readable text contrast on cream surfaces. Existing typography is retained.

The source SVG wordmark comes from [Hersheyland’s Reese’s page](https://www.hersheyland.com/reeses):
https://www.hersheyland.com/content/dam/hersheyland/en-us/life-style/brands/reeses/reeses-logo.svg
Retrieved 2026-10-29. The source lettering, proportions and colors are preserved, including its yellow and brown fills; the user-provided reference palette does not recolor the logo.

The embedded SVG tile is 144 × 192px, with 108 × 45.2px wordmarks, a 96px row pitch and 72px alternate-row offset. Opacity is 22% in light mode and 14% in dark mode. Grid lines are hidden. Only grid panels use this artwork; solid/glass surfaces omit it. Override --ngx-panel-grid-image with none to disable it. No runtime downloads or asset-copy setup are required.
